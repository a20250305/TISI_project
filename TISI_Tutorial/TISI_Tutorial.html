This tutorial calculates the pretrained Therapy-Induced Senescence Index (TISI) from a gene-by-sample RNA-seq expression matrix. It uses six GSE189764 samples: three CTL samples and three TIS persister samples.

The tutorial performs inference with the pretrained L2=10 dot-product model. It does not retrain the model.

2. Example data and provenance

The example expression file is a compact subset of the author-provided GSE189764 normalized expression matrix. It retains all genes and only the six required samples. The matrix is oriented as genes x samples:

  • the first column contains HGNC gene symbols;
  • the remaining columns are C1, C2, C3, gT1, gT2, and gT3;
  • the values are the normalized expression values used by the original RNA-seq validation pipeline, described there as normalized TPM input, not raw read counts;
  • the original scoring pipeline then applies log2(x + 1e-5), column-wise scale(), and row-centering before the dot product.

The sample annotation is supplied separately. The public GEO records identify C1-C3 as controls and gT1-gT3 as TIS persister samples. Exact GEO sample accessions are in the metadata file.

4. Preprocessing and TISI calculation

The functions below reproduce the inference steps used in the original RNA-seq validation code. They do not retrain the model.

Duplicate input genes are averaged before identifier matching. Genes that are not in the pretrained model are omitted from the dot product. The score is therefore based on the intersection of the input genes and the named model weights.

collapse_duplicate_rows <- function(mat) {
  groups <- split(seq_len(nrow(mat)), rownames(mat))
  if (all(lengths(groups) == 1L)) {
    return(mat)
  }

  collapsed <- t(vapply(
    groups,
    function(i) colMeans(mat[i, , drop = FALSE], na.rm = TRUE),
    numeric(ncol(mat))
  ))
  colnames(collapsed) <- colnames(mat)
  rownames(collapsed) <- names(groups)
  collapsed
}

prepare_model_matrix <- function(mat, model) {
  mat <- as.matrix(mat)
  storage.mode(mat) <- "numeric"
  ids <- toupper(trimws(rownames(mat)))
  rownames(mat) <- ids
  mat <- collapse_duplicate_rows(mat)

  ensembl_fraction <- mean(grepl("^ENSG[0-9]+$", rownames(mat)))

  if (ensembl_fraction > 0.5) {
    rownames(mat) <- sub("\\.[0-9]+$", "", rownames(mat))
    mat <- collapse_duplicate_rows(mat)
    mat <- mat[!duplicated(rownames(mat)), , drop = FALSE]
    return(mat)
  }

  mapping <- AnnotationDbi::select(
    x = org.Hs.eg.db,
    keys = rownames(mat),
    keytype = "SYMBOL",
    columns = "ENSEMBL"
  )
  mapping <- mapping[!is.na(mapping$ENSEMBL), , drop = FALSE]
  mapping <- mapping[!duplicated(mapping$SYMBOL), , drop = FALSE]
  mapping <- mapping[!duplicated(mapping$ENSEMBL), , drop = FALSE]

  genes_to_keep <- intersect(mapping$SYMBOL, rownames(mat))
  if (length(genes_to_keep) == 0L) {
    stop("No input genes could be matched to the model identifiers.")
  }

  mat <- mat[genes_to_keep, , drop = FALSE]
  rownames(mat) <- mapping$ENSEMBL[match(rownames(mat), mapping$SYMBOL)]
  mat
}

normalize_exp <- function(x) {
  x_log <- log2(x + 0.00001)
  x_scaled <- scale(x_log)
  row_means <- rowMeans(x_scaled, na.rm = TRUE)
  x_scaled - matrix(
    row_means,
    nrow = nrow(x_scaled),
    ncol = ncol(x_scaled),
    byrow = FALSE
  )
}

scoreOCLR <- function(profile, model, m = "dot") {
  weights <- model$w
  genes <- intersect(names(weights), rownames(profile))
  if (length(genes) == 0L) {
    stop("No model genes are present in the expression matrix.")
  }

  weights <- weights[genes]
  profile_mat <- as.matrix(profile[genes, , drop = FALSE])

  if (m != "dot") {
    stop("This tutorial uses the pretrained dot-product TISI model.")
  }

  list(apply(profile_mat, 2, function(x) weights %*% x))
}

minmax <- function(x) {
  value_range <- range(x, na.rm = TRUE)
  if (diff(value_range) == 0) {
    return(rep(0.5, length(x)))
  }
  (x - value_range[1]) / diff(value_range)
}

calculate_tisi <- function(expression_matrix, model) {
  expression_for_model <- prepare_model_matrix(expression_matrix, model)
  normalized_matrix <- normalize_exp(expression_for_model)
  raw_score <- as.numeric(scoreOCLR(
    normalized_matrix,
    model,
    m = "dot"
  )[[1]])

  list(
    scores = data.frame(
      sample_id = colnames(expression_for_model),
      TISI_raw = raw_score,
      TISI_scaled = minmax(raw_score),
      row.names = NULL,
      check.names = FALSE
    ),
    n_input_genes = nrow(expression_for_model),
    n_model_genes_used = length(intersect(
      names(model$w),
      rownames(expression_for_model)
    ))
  )
}

TISI_raw is the weighted dot product. TISI_scaled is the 0-to-1 min-max transformation used for the example. A higher score indicates a more TISI-like transcriptional state relative to the samples being scaled; it is not a probability and is not a universal clinical cutoff.

Important reproducibility note. The original Figure 2E analysis scored all 12 GSE189764 samples before selecting the six displayed samples. Because the original normalization and min-max scaling depend on the columns included in a calculation, the six-sample tutorial values are expected to differ slightly from the six Figure 2E values. The tutorial deliberately uses exactly six shipped samples so that a new user can run the example without hidden samples; the algorithm and pretrained weights are unchanged. To reproduce Figure 2E numerically, run the same functions on the complete 12-sample matrix.

7. Apply TISI to your own bulk RNA-seq data

Replace expression_file with a gene-by-sample matrix containing either HGNC symbols or Ensembl IDs. For Ensembl IDs, remove version suffixes such as .12. Use the same expression scale expected by the original pipeline and do not apply an additional log transformation before calling calculate_tisi().

user_table <- fread("path/to/my_normalized_expression.csv")
gene_column <- names(user_table)[1]
user_matrix <- as.matrix(
  user_table[, setdiff(names(user_table), gene_column), with = FALSE]
)
storage.mode(user_matrix) <- "numeric"
rownames(user_matrix) <- user_table[[gene_column]]

user_result <- calculate_tisi(user_matrix, tisi_model)
fwrite(user_result$scores, "my_TISI_scores.csv")

Check the number of matched model genes before interpreting results. A very low coverage means that the score is based on only a small part of the model. Do not compare min-max-scaled scores from unrelated datasets as if they were on a common absolute scale; retain and report TISI_raw as well.

8. scRNA-seq template (per-cell scoring)

The same inference implementation can score a gene-by-cell matrix, so scores are calculated per cell when cells are columns. The original scRNA-seq workflow uses the same gene matching, log2(x + 1e-5), scaling, centering, and dot product. It is not necessary to pseudobulk unless the scientific question requires sample-level scores.

For a Seurat object, use the assay layer that corresponds to the input scale expected by the original workflow. The code below uses the raw-count layer so that the tutorial performs the documented log transformation. The conversion to a dense matrix follows the existing implementation and can require substantial memory for large datasets.

library(SeuratObject)

# seurat_object is an existing Seurat object.
cell_matrix <- SeuratObject::GetAssayData(
  seurat_object,
  assay = "RNA",
  layer = "counts"
)

cell_result <- calculate_tisi(cell_matrix, tisi_model)
seurat_object$TISI_raw <- cell_result$scores$TISI_raw
seurat_object$TISI_scaled <- cell_result$scores$TISI_scaled

For very large sparse datasets, score cells in batches or use pseudobulk profiles after validating that the same preprocessing and gene-ID convention are preserved. The model does not produce a probability, cell type, or clinical threshold automatically; downstream grouping requires an explicitly reported rule.

9. Troubleshooting

  • Wrong orientation: the input must have genes in rows and samples/cells in columns.
  • Wrong identifiers: use HGNC symbols or Ensembl IDs. Ensembl version suffixes are removed; other identifier systems require an explicit mapping.
  • Duplicate genes: duplicate rows are averaged before matching.
  • Missing genes: unmatched genes are omitted. Inspect model coverage and report it with the scores.
  • Missing values: remove or resolve non-finite expression values before scoring; the dot product is not defined for NA, NaN, or Inf values.
  • Normalization mismatch: do not treat raw counts, TPM, already log2 values, and Seurat normalized values as interchangeable. Match the transformation used by the original pipeline.
  • No matched genes: install AnnotationDbi and org.Hs.eg.db, or provide Ensembl IDs that match the model.
